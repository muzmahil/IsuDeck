# IsuDeck 1.2.0

## Highlights

- Added online plugin catalog integration with HTTPS downloads, SHA-256 verification, plugin updates, and external ZIP installation.
- Updated the plugin SDK and user documentation.
- Added in-app update notifications with release notes, download links, and options to defer or skip a version.
- Reworked the desktop interface with clearer status feedback, improved profile and action editing, and refreshed visual styling.
- Improved native Windows input and driver handling, embedded required portable resources, and refined Linux input handling.
- Added Windows application release automation.

## Notes

- Windows release builds are published as portable executables.
- Plugin packages are checked against their declared SHA-256 hashes before installation.
